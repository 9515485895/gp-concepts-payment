GP CONCEPTS CASHFREE BACKEND

Upload these files to a GitHub repository:
- server.js
- package.json
- .gitignore
- .env.example

DO NOT upload a real .env file or Cashfree secret to GitHub.

Render:
Build Command: npm install
Start Command: npm start
Environment variables:
CASHFREE_CLIENT_ID = your Cashfree App ID
CASHFREE_CLIENT_SECRET = your Cashfree Secret Key
PUBLIC_BASE_URL = your Render service URL
